# Sinhala Sign Language Translator (SSL Translator)

**A mobile application that bridges communication between the Deaf/Hard-of-Hearing community and Sinhala speakers through real-time bidirectional translation and an integrated sign language learning module.**

**🎓 2nd Year Group Project — Department of Computer Science, University of Kelaniya**




**📖 Overview**

Communication barriers between Sinhala-speaking individuals and the Deaf community remain a significant challenge in Sri Lanka. This project aims to reduce that gap by providing an accessible mobile solution with three core capabilities:


**Sign Language → Sinhala:** Real-time recognition of Sinhala Sign Language (SSL) gestures, converted into Sinhala text.<br>
**Sinhala (Voice/Text) → Sign Language:** Converts spoken or typed Sinhala into corresponding sign language gestures (video-based).<br>
**Sign Language Education Module:** An in-app learning section to teach users basic to advanced Sinhala Sign Language through sinhala meaning with corresponding videos.<br>



**✨ Features**

**🤟 Sign Language to Sinhala (Voice/Text)**


Real-time hand gesture and sign detection using the device camera<br>
Converts recognized signs into Sinhala text<br>
Text-to-Speech (TTS) output in Sinhala<br>
Support for static signs (alphabet/words) and dynamic gestures (phrases)<br>


**🗣️ Sinhala (Voice/Text) to Sign Language**


Speech-to-Text (STT) for Sinhala voice input<br>
Text input option for typed Sinhala<br>
Converts recognized words/sentences into sign language video clips<br>
pre-recorded sign demonstration<br>


**📚 Sign Language Education Module**


Structured lessons<br>
Interactive practice with videos<br>
Offline access to lesson content<br>


**📱 General**


Cross-platform mobile application<br>
User-friendly, accessibility-focused UI/UX<br>
Offline fallback support for core translation features (where applicable)<br>


**🎯 Project Scope & Objectives**


Improve accessibility and inclusivity for the Deaf/Hard-of-Hearing community in Sri Lanka<br>
Provide a low-cost, mobile-accessible translation tool requiring only a smartphone<br>
Promote learning of Sinhala Sign Language among hearing individuals<br>
Build a foundation dataset/model for future SSL research<br>


**🧪 Limitations & Future Work**


Current gesture recognition is limited to a defined vocabulary/dataset<br>
Continuous sentence-level (grammar-aware) sign translation is a future goal<br>
Plans to expand dataset coverage and improve real-time accuracy<br>
